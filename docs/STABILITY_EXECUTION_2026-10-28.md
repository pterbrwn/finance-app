## Performance evidence

Synthetic benchmark runs used Node 24.22.1 on Linux ARM64, Cortex-A78AE. These are current candidate measurements, not claims about a prior deployed release.

| Operation | 10k rows | 100k rows |
| --- | ---: | ---: |
| SQLite budget summary, history 2016–2026 | 16.70 ms | 210.06 ms |
| Full-state budget-summary reference | 41.91 ms | 334.36 ms |
| Budget edit | 45.67 ms | 200.20 ms |
| Goal edit | 47.53 ms | 202.89 ms |
| Manual-account edit | 46.55 ms | 199.78 ms |
| Bounded transaction query, 1/3/12 months | 1.41 / 1.59 / 1.46 ms | 1.96 / 2.08 / 2.23 ms |

The indexed summary was 60% faster at 10k and 37% faster at 100k than the same-run full-state reference. At 100k the measured database/backup size was 56.7 MB, peak process RSS was about 491 MB, and whole-run event-loop delay p95 was 3.40 seconds. One-sample backup and restore times were 1.87 and 3.39 seconds; a pre-index run reported 1.16 and 2.05 seconds. Those one-sample maintenance timings are noisy, but indicate the larger index has a backup/restore cost that remains part of the performance tradeoff.
